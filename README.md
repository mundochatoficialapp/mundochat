# MundoChat (solo mayores de 18)

## Local
    npm install
    npm start      ->  http://localhost:3000

## Publicar
Ver la guía en el chat: GitHub -> Render -> dominio -> Search Console.
Reemplaza TU-DOMINIO.com y TU-CORREO@TU-DOMINIO.com en:
public/index.html, public/robots.txt, public/sitemap.xml, public/terminos.html, public/privacidad.html

## Variables de entorno (opcionales, para TURN)
TURN_URL (ej. turn:servidor:3478,turns:servidor:443?transport=tcp), TURN_USER, TURN_PASS
